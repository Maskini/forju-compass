# CEO demo — 7 November 2026

This release removes the duplicate project inquiry link from chat. There is one pink action: **Projekt vorstellen**, changing to **Projektangaben fortsetzen** once the visitor starts. English uses **Tell us about your project / Continue your project details**. The six-step form consistently calls its content project details; it no longer calls them a draft. Existing context, editing, resuming and delivery safeguards are preserved.

The previously tested conversation-clear button remains beside expand and close. Clearing requires confirmation and cancels pending answers.

## Attachment removal and video refresh

The chat no longer has an attachment button or a hidden file input. The TXT/Markdown reader, file-error state and paperclip glyph were removed as well; the composer now gives that space to the visitor's question. This applies to the website widget and standalone `/embed` chat.

The refreshed recordings were captured after that removal. Gentle camera moves, click cues and chapter captions accompany an original instrumental score composed locally with Python's standard library. There are no sampled recordings, paid generation calls, new services or production packages. The native video controls still let visitors pause, mute and enter full screen. Keyboard-accessible chapter buttons seek to relevant moments, and playing one video pauses the other.

## Known limitation

Project email delivery is **not enabled**: `/api/project-submission` reports `direct:false` without an authorized sender. The form and demo disclose this, retain the visitor's details and never show a successful receipt. Configure an authorized sender under the existing server settings before presenting project delivery as available. No real mailbox delivery was tested for this release.

## Repeat the media check

After the production build is running at `http://127.0.0.1:4283` with `COMPASS_LOCAL_ONLY=true` and isolated test quota settings:

```sh
node tools/demo/check.mjs
```

`DEMO_BASE` selects a different origin; `DEMO_OUT` selects the evidence directory. It uses synthetic questions and permits only chat POSTs. It never submits a project or report. The existing Playwright installation is in `tools/visitor-checks`.

`tools/demo/score.py` generates the original WAV. `tools/demo/export.py` edits timestamped browser frames and muxes the soundtrack with an existing local FFmpeg installation. These are development tools; they do not run on Render. `FFMPEG` and `DEMO_FONT` can select the local binary and font. There is no additional hosting plan or media service.
